# AwaitLab · 防御代码审查

打开 Python 代码，直接看重复防御检查的依据，预览差异后再决定是否简化。分析在本机完成，不导入或执行目标代码，不调用模型 API。

## 开始使用

需要 Python 3.10+ 和桌面版 VS Code，无需 pip 安装 AwaitLab。扩展0.2.0内置 AwaitLab 0.17.0 的审查引擎。

1. 安装 `awaitlab-0.2.0.vsix`，打开一个 Python 文件。也可以运行命令 **AwaitLab: 打开上手示例**。
2. 编辑后稍等，重复检查会显示黄色波浪线，“问题 / Problems”面板同步显示位置。悬停看原因，点击相关位置跳转到前置条件。
3. 在黄色提示处按 **Ctrl+.**，优先选择 **AwaitLab：只预览第…行这一处简化**；也可选择整文件预览。
4. 查看 VS Code 左右差异。在预览右上角点 **✓**，或运行 **AwaitLab: 应用当前文件的简化（可撤销）**。
5. 应用只改编辑器缓冲区，按 **Ctrl+Z** 撤销。确认后自行保存并运行自己项目的测试。

应用只修改当前预览中的建议。单处预览保留其他提示；整文件预览会显示可生成的简化数量。代码变化后旧预览不能继续应用，需要重新审查。

蓝色提示（ALD002）是需要业务判断的宽泛异常处理，不提供自动删除。忽略带理由的业务约定可使用已有的同一行语法：

```python
except Exception:  # awaitlab: ignore[ALD002] -- 可选插件失败时继续运行
    return None
```

## 配置

- `awaitlab.enabled`：是否自动审查。关闭后清除提示。
- `awaitlab.pythonPath`：Python 可执行文件路径，默认 `python`；路径包含空格时不加引号。

状态栏显示 `运行失败` 时，点击检查解释器配置，或运行 **AwaitLab: 查看运行日志**。需要 Python 3.10+；不需要模型、后台服务、账号和额外 Python 依赖。

本版是单文件本地审查，支持未保存文件。CLI 中的整仓排除和 Git 暂存区审查继续通过命令行使用；编辑器修复不会操作暂存区。分析范围是局部身份条件和有限控制流，不是任意 Python 程序的正确性证明。
